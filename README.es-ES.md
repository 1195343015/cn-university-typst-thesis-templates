Este es un proyecto de índice de plantillas de tesis en Typst alojadas en GitHub para universidades de China continental.

Alcance actual de la recopilación:

- Incluye plantillas de Typst para tesis de algunas universidades de China continental.
- Expandible a más universidades de forma sostenible.
- Solo se incluyen plantillas de tesis académicas / proyectos de fin de grado / tesis de graduación.
- Solo se incluyen repositorios de GitHub.
- Solo se incluyen repositorios con `Stars >= 16`.
- Solo se incluyen repositorios cuya fecha del último commit sea el `2025-01-01` o posterior.
- No se incluyen repositorios archivados.
- El índice se organiza por universidad.
- En principio, solo se incluye una plantilla activa por cada tipo de grado por universidad.

## Notas de recopilación

Las columnas de `Stars` y `Último commit` se sincronizan automáticamente mediante un script; se puede ejecutar manualmente `scripts/sync_github_metrics.ps1` para actualizarlas. La recopilación actual no garantiza ser exhaustiva; que una universidad o plantilla no aparezca en la lista no significa que no exista, sino que aún no ha sido incorporada al conjunto de datos actual. Si existen múltiples plantillas disponibles para el mismo grado en una universidad, se priorizará la que esté más activa en la actualidad.
